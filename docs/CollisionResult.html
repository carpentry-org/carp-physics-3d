CollisionResult

is a sum type representing the outcome of a collision check.

Physical

instantiate

(Fn [Collision] CollisionResult)

creates a Physical.

Triggered

instantiate

(Fn [Trigger] CollisionResult)

creates a Triggered.

a

defn

(Fn [(Ref CollisionResult a)] (Handle ())) 

                        (a res)

returns the handle for the first object in the collision/trigger.

b

defn

(Fn [(Ref CollisionResult a)] (Handle ())) 

                        (b res)

returns the handle for the second object in the collision/trigger.

copy

instantiate

(Fn [(Ref CollisionResult a)] CollisionResult)

copies a CollisionResult.

delete

instantiate

(Fn [CollisionResult] ())

deletes a CollisionResult. This should usually not be called manually.

get-tag

instantiate

(Fn [(Ref CollisionResult a)] Int)

Gets the tag from a CollisionResult.

prn

instantiate

(Fn [(Ref CollisionResult a)] String)

converts a CollisionResult to a string.

str

instantiate

(Fn [(Ref CollisionResult a)] String)

converts a CollisionResult to a string.
