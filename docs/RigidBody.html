RigidBody

unifies spatial state (Transform) and physical behavior (Body) into a single component.

apply-angular-impulse!

defn

(Fn [(Ref RigidBody a), (Ref (Vector3 Double) b)] ()) 

                        (apply-angular-impulse! rb impulse)

proxy to apply an instantaneous angular impulse.

apply-force!

defn

(Fn [(Ref RigidBody a), (Ref (Vector3 Double) b)] ()) 

                        (apply-force! rb f)

proxy to apply a continuous force to the underlying body.

apply-impulse!

defn

(Fn [(Ref RigidBody a), (Ref (Vector3 Double) b)] ()) 

                        (apply-impulse! rb impulse)

proxy to apply an instantaneous impulse to the underlying body.

apply-torque!

defn

(Fn [(Ref RigidBody a), (Ref (Vector3 Double) b)] ()) 

                        (apply-torque! rb t)

proxy to apply a continuous torque to the underlying body.
