Integrator

step!

defn

(Fn [(Ref Transform a), (Ref Body b), Double] ()) 

                        (step! t b dt)

advances the simulation state by dt using a default 60Hz sub-step size.

step-custom!

defn

(Fn [(Ref Transform a), (Ref Body b), Double, Double] ()) 

                        (step-custom! t b dt sub-step-size)

advances the simulation state by dt using a custom sub-step size. Only integrates bodies of type Dynamic that are not sleeping.
